Class: Converter

Converter()

Class for parsing a XML file and extracting a schematic. This static class contains many helper functions to extract information from the file. The extracted node of the schematic view can than be passed to Schematic.fromXML.

(static) assertTagFound(variable, tagname)

Internal helper function for checking if a variable is correctly set.

The message of the thrown error depends on the data type. If an variable is falsy (null, undefined, etc.) a error with the message "XML-Tag not found: <tagname>" is thrown. If the variable is an empty array, the message is instead "Filtered list of tags is empty: <tagname>".
